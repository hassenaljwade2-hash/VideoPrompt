# 🎬 فيديو برومبت (تطبيق أندرويد)

تعطيه فيديو، فيستخرج منه الصوت ويحول الكلام لنص (مع التوقيتات وملف ترجمة SRT)، ويكتب برومبت كامل عن الفيديو، وبعدين يحط كلشي بملف ZIP بمجلد التنزيلات: `Download/VideoPrompt`.

**محتويات ملف ZIP:** `prompt.md` و`transcript.txt` و`transcript_timestamps.txt` و`subtitles.srt` و`audio.wav` و`info.json`، ومجلد `frames/` بيه لقطات من الفيديو.

---

## 1) سوّي ملف APK مجاناً (حتى من التلفون)

1. سوّي حساب على **github.com**.
2. اضغط **+ ← New repository**، وسمّه `VideoPrompt`، وخليه Public أو Private، وبعدين **Create**.
3. اضغط **uploading an existing file** وارفع كل ملفات هذا المشروع، **مع مجلد `.github`**.
   - إذا ما كدرت ترفع مجلد `.github` من التلفون: اضغط **Add file ← Create new file**، واكتب بالاسم
     `.github/workflows/build-apk.yml`، والصق محتوى الملف.
4. روح لتبويب **Actions**، فيبدي البناء تلقائياً (أو اضغط **Build APK ← Run workflow**).
5. بعد ما يخلص (تقريباً 3-5 دقائق) افتح البناء، ومن تحت **Artifacts** نزّل **VideoPrompt-APK**.
6. فك الضغط ونصّب `VideoPrompt.apk` على التلفون، ووافق على "التثبيت من مصادر غير معروفة".

## 2) مفتاح API مجاني (مرة وحدة)

1. ادخل **console.groq.com/keys** وسجل دخول.
2. اضغط **Create API Key** وانسخ المفتاح (يبدي بـ `gsk_`).
3. افتح التطبيق، وروح على **⚙️ الإعدادات**، والصق المفتاح واضغط **حفظ**.

## 3) الاستخدام

اختار الفيديو، وحدد اللغة، واضغط **▶️ ابدأ**، وبعدين **💾 حفظ ملف ZIP**.

### ملاحظات
- التفريغ يستخدم **Whisper large-v3**، وهو من أدق الموديلات للعربي.
- الفيديوات الطويلة تتقسم تلقائياً لأجزاء كل جزء 10 دقائق.
- الفيديوات الكبيرة جداً (أكثر من ساعة أو أكبر من 1GB تقريباً) ممكن تثقل على ذاكرة التلفون.
- تكدر تستخدم OpenAI بدل Groq: غيّر الرابط بالإعدادات إلى `https://api.openai.com/v1`، وموديل التفريغ إلى `whisper-1`، وموديل البرومبت إلى `gpt-4o-mini`.
